# Лаборатория методов — спецификация эксперимента

Идея (как лаборатория Бориса Черни по статьям о жидкости): одна сцена — несколько **методов расчёта** с одинаковыми входными данными. Ученик выбирает сцену, крутит условия, включает/выключает методы и видит: живой экран, таблицу результатов, общий график, а для каждого метода — уравнение с подставленными числами, настоящий код функции, цитату из книги с номером страницы и вердикт сверки.

Аудитория: школьники 12–16 лет без физики. Тексты — простым русским, каждое новое слово объяснено. Числа — с запятой (используй `fmt` из kit.mjs). Минус — типографский (fmt делает сам).

## Файл

`src/methods/exp-<id>.mjs`, чистый ES-модуль без DOM на верхнем уровне (чтобы его можно было импортировать в node для тестов). Образец: `src/methods/exp-waves.mjs`. Движок: `src/methods/kit.mjs` (читать обязательно). Ничего, кроме своего файла, не менять.

## Требования

1. **Методы честные.** Минимум 3 метода, хотя бы один — «как в книге», хотя бы один — «глубже книги» (настоящая физика/инженерная модель). Все считают ОДНУ и ту же величину (metric) из ОДНИХ и тех же параметров P, чтобы сравнение было честным.
2. **Книга — первоисточник.** Текст книги: `data/book-pages.json` (массив глав, у каждой `pages: [{page, text}]`). Цитаты в `refs` — **дословные** куски текста страницы (kit проверяет: нормализует пробелы и ищет подстроку; если не найдено — показывает «пересказ»). Ищи страницы скриптом в node. Номер страницы — поле `page`.
3. **Сверка.** `review.status`:
   - `match` — метод совпадает с книгой (формула/числа те же);
   - `simplified` — книга даёт только словами/грубо, метод добавляет пороги и коэффициенты из практики;
   - `beyond` — метода нет в книге, это физика глубже;
   - `review` — не уверен.
   `tol` — с ЧИСЛОМ: «в 12 тестовых случаях отличие от численной модели не больше 0,8 мин» и т. п. Числа получи тестом в node (сделай `export const __test = {...}`, если нужно).
4. **Экран яркий и живой.** Canvas 2D, тёмный фон-экран (#070b16…#0b1020), насыщенные цвета, свечение (`shadowBlur`), плавная анимация. Учитывай `dpr` из `fitCanvas(canvas)` — все размеры линий и шрифтов умножай на dpr. При `calm === true` (пониженная анимация) не дёргай картинку, но состояние показывай. Экран должен понятно показывать СУТЬ расчёта (не украшение).
5. **Производительность:** кадр ≤ 6 мс на ноутбуке; `run` без симуляции — микросекунды; `sweep` вызывается ~60 раз на каждое изменение.
6. **Без внешних библиотек, без сети.** Только Canvas 2D и чистый JS.
7. **Тексты:** короткие, конкретные, без воды и без слов «уникальный», «революционный». Объясни каждый термин при первом появлении.
8. **Проверка перед сдачей:**
   - `node -e 'import("./src/methods/exp-<id>.mjs").then(m=>{const e=m.default; for(const s of e.scenes){const P={}; e.params.forEach(p=>P[p.id]=p.value); Object.assign(P,s.set); for(const mm of e.methods) console.log(s.id, mm.id, mm.run(P,s))}})'` — без ошибок, числа разумные;
   - все цитаты из `refs` найдены в `data/book-pages.json` на указанной странице;
   - каждое имя из `src` — существующая именованная функция верхнего уровня.
