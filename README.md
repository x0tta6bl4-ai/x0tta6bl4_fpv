# FPV Anatomy

Интерактивный учебник по книге «FPV-дрон: понять, а не зазубрить» (редакция 7): 21 глава, приложения,
у каждой главы — стенд с заданиями. Одна HTML-страница, работает без сервера, в основном с телефона.

## Где открыть

- **https://x0tta6bl4-ai.github.io/x0tta6bl4_fpv/** — публичный сайт, обновляется сам после каждого слияния в `main`
  с зелёными тестами (без текста и сканов книги). Ссылку можно давать тем, кто учится.
- Приватная версия со сканами книги — на claude.ai (публикует Claude).

## Быстрый старт

```bash
npm install
npx playwright install chromium   # браузер для автотестов (один раз)
npm run build                     # → dist/fpv-anatomy-v4.html
npm test                          # сборка + 15 автотестов (~15 мин)
```

## Документы

- `AGENTS.md` — общие правила для всех ИИ-ассистентов (читать первым).
- `docs/ROLES.md` — кто что делает: Claude, GPT, Gemini.
- `docs/WORKFLOW.md` — ветки, Pull Request, проверки, публикация.
- `docs/ARCHITECTURE.md` — устройство проекта и API стендов.
- `docs/BACKLOG.md` — первые задачи.

## Лицензии

Набор рисунков `kit/` и `scripts/` — Anatomy (MIT, см. `kit/LICENSE.txt`).
Текст и сканы книги (`data/book-pages.json`, `data/book-images.json`) принадлежат автору книги и в git **не хранятся**
(репозиторий публичный). Без них учебник собирается и все тесты проходят — нет только раздела «Материал книги».
Файлы передаются владельцем отдельно: положить в `data/` — `.gitignore` не даст их закоммитить.
