- Статус: готово

- PR: —

## Цель
Постоянная ссылка для владельца и тех, кто учится: учебник обновляется сам после каждого слияния, без ручной публикации.

## Что сделано
- `.github/workflows/pages.yml`: после зелёного `tests` на `main` (или вручную) — сборка без книги, `noindex` для поисковиков,
  `version.txt` с коммитом, выкладка на https://x0tta6bl4-ai.github.io/x0tta6bl4_fpv/.
- README и WORKFLOW: где сайт, как включить, как узнать версию.

## Готово, когда
- Владелец включил Pages (Settings → Pages → Source: GitHub Actions), первый запуск `pages` зелёный, сайт открывается на телефоне.

## Журнал
- 2026-10-20: сборка сайта проверена локально без книги: 2,7 МБ, гл. 3 открывается, ошибок в консоли нет.
