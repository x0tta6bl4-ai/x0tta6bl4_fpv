# Доска задач

Одна задача — один файл `NNN-кратко.md` (номер по порядку). Каждый ассистент правит только карточки своих задач,
поэтому конфликтов при слиянии нет. Новую задачу заводит владелец или Claude.

## Формат карточки

```markdown
# NNN. Название

- Исполнитель: claude | gpt | gemini
- Статус: новая | в работе | на ревью | готово | не сделано
- Ветка: gpt/ch17-cases
- PR: (ссылка, когда открыт)
- Зависит от: NNN (если есть)

## Цель
Что должно получиться и зачем (1–3 предложения).

## Что сделать
Конкретные шаги и файлы.

## Готово, когда
Проверяемые признаки: какие файлы есть, какие тесты прошли, что видно на телефоне.

## Журнал
- 2026-10-20: что сделано, что осталось, на чём остановился.
```

## Статусы

- **новая** — никто не взял;
- **в работе** — исполнитель открыл ветку;
- **на ревью** — PR открыт, ждёт проверки;
- **готово** — PR слит в `main`;
- **не сделано** — честный отказ с причиной в журнале (лучше, чем подгонка).
