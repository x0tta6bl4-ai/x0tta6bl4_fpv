## Что сделать
1. От свежего `main` перенести только геометрию: новые `Mesh` в `build()` — в существующие группы деталей
   (`radio`, `goggles`, `gant`, `frame`, `fc`…), координаты подогнать под корпуса Grok.
2. Не менять `add()`: в ветке он копирует цвет каждой детали (`color.slice()`), а цвет мостов и пакетов намеренно
   общий по ссылке (`s.cmdColor` / `s.vidColor` — `paint()` перекрашивает мост в серый). Копию для приглушения деталей
   уже делает `theme()` (только для деталей без `lane`).
3. Не переносить вторую реализацию K1–K6, свой `tests/path3d-novice.mjs` и `.github/workflows/path3d-novice.yml` —
   они дублируют то, что в main; проверки, которых нет в нашем тесте, — дописать в него.
4. Касание: новые детали не должны перехватывать касание середины мостов и `rx`/`vtx` (тесты `path3d`, `path3d-novice`).
