## Цель
Правила и автоматические проверки, чтобы ассистенты работали в одном репозитории и не ломали чужое.

## Что сделать

- Доска задач `docs/tasks/`, правила работы с задачей в `AGENTS.md`.
- `.gitattributes`: концы строк LF (Windows + Linux).

## Готово, когда

- `npm run zones` локально проверяет текущую ветку.
