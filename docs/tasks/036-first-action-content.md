## Что сделать
Файл `docs/content/first-action.json` — 25–35 ситуаций, где важно **первое действие** (полёт, стол, зарядка, первая
помощь). Источник — ситуации С1–С40 и связанные вопросы таблицы. Каждая запись:
```json
{ "id": "fa01", "srez": ["С37"], "chapter": 18, "place": "air|bench|charge|safety",
  "cue": "Что видит или слышит пилот — 1 фраза, без ответа внутри",
  "options": [ { "text": "действие", "correct": true, "why": "почему это первым" },
               { "text": "…", "correct": false, "why": "почему не это / не сейчас" } ],
  "then": "что дальше, когда первое действие сделано (1–2 фразы)",
  "seconds": 6 }
```
Правила:
1. 3–4 варианта, ровно один верный; неверные — правдоподобные ошибки новичка, не абсурд.
2. Верный ответ — как в срезе; где срез неточен — как в учебнике, с полем `"note"` («на срезе — X»).
3. `cue` не подсказывает ответ словами из верного варианта.
4. `seconds`: 5–8 для полёта, 10–15 для стола/зарядки; первая помощь — без таймера (`null`).
5. Никакого военного применения; первая помощь — только то, что есть в срезе (С39, С40) и гл. 18.

## Готово, когда
- JSON разбирается, у каждой записи ровно один `correct: true`, у каждого варианта есть `why`;
  в PR — таблица «ситуация → номер среза → глава».
