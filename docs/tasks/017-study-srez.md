- Исполнитель: ведущий инженер (по поручению владельца)

## Цель
1. Восстановить правильный педагогический порядок элементов в главах учебника (цели и новые слова — до стенда и объяснений, как описано во введении).
2. Сделать цветные блоки (`.blk`) свёрнутыми по умолчанию через `<details>` / `<summary class="blk-h">`, устранив мобильный эффект «стены текста» и сохранив тач-мишень от 44 px.
3. Добавить интервальное расписание повтора для колоды «Срез (143)» в тренажёре Главы 20.
4. Добавить режим «Пробный срез (20 вопросов)» в Приложение «И. Вопросы среза» с показом результата и ссылок на ошибки в главах.
5. Создать автотест `tests/study.mjs` и обеспечить полный зелёный регресс `npm test` и `npm run zones`.

## Что сделать
1. `src/app.mjs`:
   - В `chapterView(ch)` переместить блок целей и новых слов (`goals`) перед `kidHtml` и `interactiveHtml`.
   - В `blockHtml(b)` рендерить блоки через `<details class="blk" data-type="${b.type}">` с `<summary class="blk-h">`. Ключевые блоки (`key`) оставлять открытыми по умолчанию (`open`).
   - В приложении «И» (`srezHtml` / обработчики) добавить переключатель режимов «Каталог (143)» и «Пробный срез (20)» с прохождением экзамена, подсчётом очков и разбором ошибок.
2. `src/labs/quiz.mjs`:
   - Для колоды «Срез» реализовать интервальное повторение (`fpv_srez_sched`): при ответе «Знал» интервал возрастает (1 → 3 → 7 → 14 → 30 дней), при ответе «Не знал» карточка сбрасывается на повтор сегодня.
   - Очередь колоды «Срез» в первую очередь выдаёт карточки, срок повтора которых наступил.
3. `src/style.css`:
   - Стили для `<details class="blk">` и `<summary class="blk-h">` с эргономичной высотой клика $\ge 44$ px, маркером раскрытия и отсутствием сдвигов.
   - Стили для экрана и кнопок «Пробный срез».
4. `tests/study.mjs`:
   - Автотест всех 4 компонентов: порядок главы, свёртывание блоков, расписание колоды, пробный экзамен.
5. Обновить `tests/run-all.mjs`, запустить регресс `npm test` и проверить зоны `npm run zones`.
