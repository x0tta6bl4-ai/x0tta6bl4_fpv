## Что сделать (`data/chapters-b.mjs`, поле `core` гл. 10; новых фактов не добавлять)
Движок теперь показывает `core` так: стенд первым, под ним темы-аккордеон. Тема = абзац `<p><b>Заголовок</b></p>` и всё
до следующего такого абзаца. Жирная строка **с точкой на конце** — не тема, а открытое предупреждение.
1. Первым абзацем — одно предупреждение: «Подключение батареи и проверки на столе — без винтов.» Сейчас оно стоит
   между ELRS и UART, и абзац про UART движку приходится приклеивать к первой теме.
2. 5–6 тем, заголовок — как вопрос новичка, до 6 слов («Как команда доходит до моторов?», «Почему нет бинда?»…).
   Тема — не больше ~80 слов: одна мысль, одно действие. Лишнее — в «Подробнее» (там весь прежний текст главы).
3. Итог гл. 10 говорит «DShot», а в «Главном» его нет: убрать из итога или объяснить одной фразой в первой теме.
4. Связь со стендом «Связка пульт — приёмник» (`src/figs/pair.mjs`, детали: пульт, приёмник, полётник, Betaflight):
   в `docs/content/ch10-core-map.md` — таблица «деталь стенда → тема "Главного"». По ней Claude сделает следующий шаг:
   касание детали открывает её тему.
5. Обновить карту 21/21 под новые темы (фрагменты должны остаться в `core`).
6. «Рентген-карточка» деталей стенда (решение владельца по советам 27.10): для 4 деталей стенда гл. 10 — пульт,
   приёмник, полётник, Betaflight — по 4 короткие строки: **что это · откуда получает · куда передаёт · что будет при
   отказе** (пример для приёмника: «принимает команды пульта по радио · антенна от пульта · полётнику по UART (CRSF) ·
   нет команд — дрон уходит в Failsafe»). Только из текста главы, глав 1, 11, 16 и книги, без новых фактов.
