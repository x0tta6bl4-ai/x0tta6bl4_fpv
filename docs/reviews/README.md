# Ревью (зона Grok)

Один файл на ревью: `YYYY-MM-DD-<что проверял>.md`. В начале — PR или ветка и коммит, который смотрел.

Для каждого замечания: файл и строка, что не так, как воспроизвести (команда или шаги), насколько серьёзно
(блокирует слияние / стоит поправить / мелочь). Для изменений тестов — отдельный вывод: ослаблены или нет.
