# Сценарии и тексты (зона GPT)

Сюда кладутся сценарии новых разборов до того, как Claude сделает из них сцену.
Формат сценария — по образцу `src/figs/armcase.mjs` (`STEPS`, `CAUSES`, `evidence`):

1. Симптом (что видит пилот).
2. Шаги проверки по порядку книги: что делаешь руками → что видишь в норме.
3. Причины: на каком шаге видна, что видно, верное исправление и 2 неверных с объяснением «почему нет».
4. Источник: страница книги и/или раздел документации.
