Карта ниже содержит ровно 21 запись `srez-coverage.json` с `ch: 10`. «Цитата where» воспроизведена из карты дословно (некоторые исходные цитаты обрываются; здесь они не дописаны). Метка перед цитатой указывает исходное место. Фрагменты core приведены дословно после удаления HTML и схлопывания пробелов. ## Сложность (П8): что заменяется и что объяснено дополнительно

Умение: различать радиосвязь и путь команды к полётнику, проверить совместимость пары, порядок каналов, профиль и выход из Wi-Fi. При интеграции 042 core заменяет видимый длинный путь; все исходные sections целиком сохраняются в одном «Подробнее». Сейчас движок main ещё не отображает core: сокращение страницы этим PR не заявляется.

Фразы core — сжатые переформулировки источников, а не новая тема. Для новичка добавлены пояснения, которые не являются дословными where: TX/RX, UART, полётник и Betaflight; диапазон и прошивка; JR; канал, CH/AUX, буквы TAER; Off, Model Match, Airport; Packet Rate, RSSI/LQ и OSD; названия пунктов Channel Map/Mixes. Они заменяют употребление сокращений без определения. DShot и номера региональных доменов из исходного макета убраны из core: для 21 ответа здесь они не нужны. Новых блоков, вкладок и заданий нет.

Источники пояснений — существующие разделы главы 10, азбука/два канала, гл. 11, глоссарий и процедуры, уже перечисленные в where. Порядок проверки по одному стику без винтов — действующая процедура, а не новая задача. Эти переформулировки и определения явно перечислены для проверки 044; фраза «видимых слов вне where нет» не заявляется.
