# Как устроен проект

## Сборка

`build.mjs` (esbuild) собирает всё в один HTML-файл: код из `src/`, стили `src/style.css` + `kit/iso.css`,
данные из `data/`. Команды — в `package.json`:

- `npm run build` → `dist/fpv-anatomy-v4.html` (со сканами страниц книги);
- `npm run build:dev` → `dist/dev.html` (без сканов, быстро; его открывают тесты);
- `npm run build:artifact` → `dist/fpv-anatomy-artifact.html` (для публикации на claude.ai).

## Папки

| Путь | Что там |
|---|---|
| `src/app.mjs` | Учебник: оглавление, глава, задания и звёзды, панель «Текущее задание», вкладки стендов главы |
| `src/stage.mjs` | Оболочка стенда: рамка, масштаб, касание детали → описание, плашки итога, камера на телефоне, панель разбора |
| `src/zoom.mjs` | Масштаб сцены: щипок, кнопки, программная камера |
| `src/figkit.mjs`, `kit/` | Набор для изометрических рисунков (Anatomy, MIT) |
| `src/figs/*.mjs` | Стенды глав — по одному файлу на стенд |
| `src/labs/*.mjs` | Плоские лаборатории (гл. 20 — карточки) и 3D-модель дрона (`drone3d.mjs`, вкладка гл. 3) |
| `src/gl3d.mjs` | Свой маленький 3D-движок на WebGL: сетки из коробок и тел вращения, свет, вращение пальцем, щипок, выбор детали касанием. Без three.js (тот +500 КБ) |
| `data/chapters-*.mjs` | Текст глав: разделы, вопросы, слова, какой стенд (`fig` / `figs`; вкладкой может быть и лаборатория: `{ "lab": "drone3d", "tab": "…" }`) |
| `data/hints.mjs` | Подсказки «Как / Почему» к заданиям, ключ `id стенда:id задания` |
| `data/intros.mjs` | Карточка «Зачем / Что делаешь / Что на столе» над стендом |
| `data/book-pages.json`, `data/book-images.json` | Исходный текст и сканы книги — **не менять, не коммитить** (вне git; без них нет раздела «Материал книги») |
| `tests/` | Автотесты (Playwright), запуск `npm test` |

## Стенд: что экспортирует файл `src/figs/<id>.mjs`

- `meta` — `id`, `title`, `keys` (обозначения), `caption`, `missions` (задания), необязательно `proc: true` (панель разбора).
- `render(state)` → `{ svg, P, labels, ... }`. `labels` — детали: `{ text, at | pick, info, tone? }`; касание детали показывает `info`.
- `defaults`, `controls` — условия опыта: `range`, `seg`, `select`, `check`, `sticks`, `hidden`. `rebuild: true` — пересобрать сцену,
  `resets` — сбросить другие условия, `sets` — включить скрытые.
- `controller(root, built, state)` → объект с методами:
  - `tick(dt, calm, state)` — кадр анимации;
  - `facts()` — что проверяют задания;
  - `readout()` — строка итога (плашки под сценой; `✗ …` красная, `✓ …` зелёная);
  - `metrics()`, `note()` — таблица и текст под сценой;
  - необязательные: `explain(плашка)`, `follow()` (камера на телефоне), `pick` / `tap` (выбор деталей),
    `panel(state)` + `act(действие, state, apply)` — панель пошагового разбора (см. `armcase.mjs`).

Задание (`missions[]`): `id`, `text`, `check(facts, state)`, `predict` (прогноз до опыта), `confirm` (вопрос после),
`setup` (с чего начинается опыт — применяется после ответа на прогноз), `look` / `touch` / `see` (что подсветить).
