Дата: 2026-10-21  
Ветка: `gemini/mobile-tables-cards`  
Зона ответственности: стили, мобильная эргономика (`src/style.css`, `docs/qa/`, `docs/tasks/`)

## 1. Проблема

1. **Горизонтальное переполнение таблиц на 360–390 px:**
   В правиле `.t` ранее были заданы десктопные размеры: `font-size: 14px; padding: 7px 10px;`. На экранах смартфонов 360 px (контейнер контента 328 px) даже компактные трёхколоночные таблицы вызывали появление горизонтальной полосы прокрутки:
   - Гл. 17 (Флаги арминга): `scrollWidth = 335 px` на контейнере 328 px (+7 px лишних, ненужный скролл);
   - Гл. 18 (Чек-лист «Летим / откладываем»): `scrollWidth = 346 px` (+18 px лишних);
   - Гл. 18 (Аварийные ситуации): `scrollWidth = 342 px` (+14 px лишних);
   - Гл. 15 (Процедура настройки): `scrollWidth = 388 px` (+60 px лишних);
   - Гл. 6 (Типы аккумуляторов): `scrollWidth = 488 px` (+160 px лишних).

2. **Кнопки самооценки в карточках итогового теста (Глава 20):**
   Кнопки выбора «✗ Не знал» и «✓ Знал» (`.fc-btns`) имели отступ `gap: 8px` и монохромные серые рамки, что в мобильном режиме повышало риск промаха пальцем и случайной оценки противоположным ответом.

## 2. Реализованные изменения

В `src/style.css`:
1. **Адаптивные стили для `table.t` на мобильных экранах:**
   ```css
   @media (max-width: 600px) {
     table.t { font-size: 12.5px; line-height: 1.35; margin: 8px 0; }
     table.t th, table.t td { padding: 5px 6px; }
   }
   ```
2. **Эргономика и разделение кнопок самооценки (`.fc-btns`):**
   ```css
   .fc-btns { display: flex; gap: 12px; width: 100%; }
   .fc-btns .lab-btn { flex: 1; min-height: 54px; font-size: 16px; border-radius: 12px; font-weight: 600; }
   .fc-btns .lab-btn.bad { background: color-mix(in srgb, var(--bad) 12%, var(--anatomy-card)); border: 1.5px solid color-mix(in srgb, var(--bad) 40%, transparent); color: var(--bad); }
   .fc-btns .lab-btn.good { background: color-mix(in srgb, var(--ok) 12%, var(--anatomy-card)); border: 1.5px solid color-mix(in srgb, var(--ok) 40%, transparent); color: var(--ok); }
   ```

- **Все** трёхколоночные таблицы глав 15, 17, 18 полностью помещаются в экран (`overflow: false`, `scrollWidth = 358 px` при ширине контейнера 358 px).
- Горизонтальный скролл полностью устранён там, где он вызывался лишь избыточным десктопным паддингом.
