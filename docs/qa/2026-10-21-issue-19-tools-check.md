## 1. Контекст

Issue #19 зафиксировал два вопроса после слияния PR #13:
1. В коммите слияния PR #13 правило `.fig-tools button` с высотой 44 px отсутствовало в мобильных медиа-запросах (кнопки оставались 38 px / 34 px). Требовалось провести инструментальный замер `getBoundingClientRect()` на ширинах 360–412 px и вернуть целевой размер $\ge 44$ px с доказательствами.
2. В `docs/qa/2026-10-20-phone.md` объяснение сбоя задания 2 (yaw) условием `Math.abs(r.in.yaw) > 0.2` не соответствовало исходному коду `src/figs/flyfield.mjs` (где сравнивался накопленный угол `s.yaw - s.yaw0` с `YAW_GOAL`). Требовалось уточнить причину.

## 3. Уточнение анализа сбоя по рысканию (Глава 2, Задание 2)

В первоначальном аудите `docs/qa/2026-10-20-phone.md` было сделано предположение, что задание сбрасывается из-за условия `Math.abs(r.in.yaw) > 0.2`.

Анализ `src/figs/flyfield.mjs` показал:
1. Условие `Math.abs(iy) > 0.2` (где `iy = r.in.yaw`) используется только в строке 178 для вывода обучающего текста `s.msg` («Поворот вправо: полётник ускоряет винты...»).
2. Зачёт задания происходит по условию:
   ```js
   if (air) {
     s.air = true;
     if (s.yaw0 === null) s.yaw0 = s.yaw;
     if (Math.abs(s.yaw - s.yaw0) > YAW_GOAL) s.yawTurned = true;
   }
   ```
   где `YAW_GOAL = 2.6` рад (~149°), а `air` требует висения дрона (`s.h > 0.05` при газе $\ge 0.5$).
3. При отпускании пальца со стика он мгновенно центрируется (`iy = 0`), а вращение дрона гасится трением (`s.wy *= 1 - dt * 4`). Если ученик отпускал стик на угле ~120–140°, дрон плавно останавливался до достижения порога 149°, а отсутствие индикатора создавало ложное ощущение, что задание «сбросилось при отпускании».
4. В коммите `e3ffc52` добавлена визуализация оставшегося угла в строке состояния над сценой (`readout`):
   ```js
   const turned = s.yaw0 === null ? 0 : Math.round((Math.abs(s.yaw - s.yaw0) * 180) / Math.PI);
   const goal = Math.round((YAW_GOAL * 180) / Math.PI);
   const yawChip = s.yawTurned ? " · ✓ развернулся" : s.air && turned >= 10 ? ` · разворот ${Math.min(turned, goal)}° из ${goal}°` : "";
   ```
   с пояснением: «Держи левый стик вбок, пока не дойдёт до цели: отпустишь — винты выровняются, дрон затормозит и остановится. Тогда просто доверни».

Аудит `docs/qa/2026-10-20-phone.md` обновлён и приведен в полное соответствие с логикой движка.
