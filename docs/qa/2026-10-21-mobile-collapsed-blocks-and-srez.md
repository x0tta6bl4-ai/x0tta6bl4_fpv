# Отчёт QA: Мобильная проверка свёрнутых блоков, колоды «Срез» и режима экзамена

Дата: 2026-10-21  
Проверено на ветке: `claude/study-srez` (PR #36)  
Исполнитель: QA / Мобильная эргономика  
Разрешения: 360 × 740 px (Android Compact), 412 × 915 px (Android Standard / Pixel)  
Темы: тёмная (`data-theme="dark"`) и светлая (`data-theme="light"`)  

---

## 1. Резюме

В рамках проверки задач по мобильной эргономике и педагогическому порядку (Задача 017) были детально протестированы:
1. **Свёрнутые блоки заметок (`details.blk`) в главах**:
   - Вертикальная высота списка из 8–9 монолитных заметок в Главе 17 снизилась с **3200+ px** до **403–425 px** (сокращение высоты страницы на **~87%**).
   - Высота кликабельного заголовка `summary.blk-h` строго выдержана: **$\ge 44$ px** (Touch Target по стандарту WCAG 2.5.5 / Apple HIG).
   - Раскрытие блоков плавное, без сдвига контента; ключевые блоки (`key`) остаются открытыми по умолчанию (`open`).
   - Горизонтальный скролл полностью отсутствует (`diff = 0`).
2. **Колода «Срез (143)» в тренажёре Главы 20**:
   - Работает приоритетная выдача карточек с наступившим сроком интервального повторения (`fpv_srez_sched`: 1, 3, 7, 14, 30 дней).
   - Индикатор статуса и счётчик на карточке отображаются корректно в обеих темах.
3. **Приложение «И. Вопросы среза» и режим «Пробный срез (20 вопросов)»**:
   - На странице `#И` добавлен переключатель режимов «Каталог (143)» и «Пробный срез (20)».
   - Прохождение пробного экзамена (вопрос → раскрытие ответа → самооценка «Ответил точно» / «Не знал») функционирует без сбоев.
   - Экран результатов отображает итоговый балл, перечень допущенных ошибок и кликабельные глубокие ссылки `[data-srz-sec]` для быстрого повторения теории в главах.

## 2. Результаты инструментальных замеров

### 2.1. Свёрнутые блоки (`details.blk`) в Главе 17

| Параметр | До изменений (монолитные `.blk`) | После изменений (`details.blk`) | Статус |
|---|---|---|---|
| Высота 9 заметок на 360 px | ~3250 px | **425 px** | PASS (сокращение на 87%) |
| Высота 9 заметок на 412 px | ~2700 px | **403 px** | PASS (сокращение на 85%) |
| Минимальная тач-мишень `summary.blk-h` | Не кликабельно | **44.0 px** | PASS ($\ge 44$ px) |
| Горизонтальное переполнение (`diff`) | 0 px | **0 px** | PASS |
| Высота блока при раскрытии | 419–539 px | **211–235 px** | PASS |

### 2.2. Колода «Срез (143)» в Главе 20

- Переключение колоды: выбор `button[data-pool="srez"]` переключает пул без сброса общего интерфейса.
- Сохранение расписания в `localStorage`: ключ `fpv_srez_sched` корректно фиксирует `step`, `interval` и `due`.
- Отсутствие горизонтального скролла: `document.documentElement.scrollWidth === window.innerWidth` (`diff = 0`).

### 2.3. Приложение «И»: Режим пробного среза

- Переключение режимов: клик по `#srz-mode-exam` мгновенно скрывает каталог 143 вопросов и отображает карточку экзамена (`#srz-exam-view`).
- Оценка: кнопки `#exam-act-reveal`, `#exam-act-good`, `#exam-act-bad` имеют высоту $\ge 44$ px и удобны для пальца.
- Разбор ошибок: допущенные ошибки собираются в список `.srz-miss-item` с сохранением цитаты и ссылки на раздел главы.
- Кнопка `#srz-exam-to-cat` возвращает исходный каталог 143 вопросов.
