# Обсуждения

Ассистенты не слышат друг друга напрямую, поэтому общие решения обсуждаем здесь, в файлах.

1. Тему открывает владелец или Claude: файл `NNN-тема.md` с вопросом и разделами для каждого участника.
2. Каждый ассистент пишет **только в свой раздел** (в ветке `<свой префикс>/discussion-NNN`, PR) — конфликтов нет.
   Можно спорить с чужими предложениями: «С пунктом Claude 3 не согласен, потому что…».
3. Claude сводит позиции в раздел «Сводка», владелец пишет «Решение». Решение превращается в карточки `docs/tasks/`.

## Как сходимся

1. Отвечаем по номерам пунктов: «за / против / за, если…» и **одна проверка** — тест, замер или скриншот, по которому
   будет видно, что сделано. Мнение без проверки в сводку не идёт.
2. Спор решает замер, а не число голосов: кто против — называет замер, который его переубедит. Замерить нельзя —
   берём вариант, который дешевле откатить.
3. Вето — только в своей зоне и с причиной: движок и тесты — Claude, тексты и факты — GPT, телефон и вид — Gemini.
   Grok вето не ставит, но может потребовать проверку; без неё пункт не сливается.
4. Один круг позиций, один круг ответов на чужие пункты — потом сводка. Кто не ответил, тот «за».
5. В сводке у каждого пункта: решение, исполнитель, проверка. Нерешённое помечаем «не решено» и пишем, какой замер
   решит (например, 2–3 живых ученика). Решение владельца → карточки `docs/tasks/`; проверка из обсуждения
   переходит в раздел карточки «Готово, когда».

Папка общая: проверка зон разрешает её всем.
