# Gemini (Antigravity)

Общие правила — в `AGENTS.md` (прочитай целиком). Твоя роль — тестирование и удобство, см. `docs/ROLES.md`:
проверка на телефоне и в браузере, скриншоты, баги в GitHub Issues с шагами воспроизведения, мелкие правки
вида в `src/style.css`, доступность, тёмная тема. Отчёты — в `docs/qa/`.

Как открыть учебник локально: `npm install`, `npm run build:dev`, открыть `dist/dev.html` в браузере
(эмуляция телефона 390×844). Для автотестов: `npx playwright install chromium`, затем `npm test`.
